Lesson 0003

把具體成果包裝成影響力實驗

這堂課不練「再多做一個成果」，而是練習把一個已經存在的成果，放到合適的平台，設計一個最小發布與反饋實驗。

今天的勝利條件：選一個具體成果，決定平台、分發方式、期待反饋，以及它未來可能變成的 product / offer。

五步驟

1. Pick
選一個已完成或 70 分的成果。
2. Audience
它是給誰看的？past self、工程師、創作者、客戶？
3. Package
放 Digital Garden、LinkedIn、repo、newsletter 還是 service page？
4. Distribute
要怎麼讓人看到？短文、留言、repo、newsletter、DM？
5. Learn
發布後要觀察什麼？保存、留言、詢問、訂閱、star？

練習 1：選平台

情境 A：你有一篇還會持續修改的長文，想保留 canonical version。

情境 B：你做了一組 HTML lesson / prompt / skill，想讓別人可以 fork 或參考。

情境 C：你想測試一個職涯 / AI 協作觀點是否能引起專業圈反饋。

練習 2：設計最小發布實驗

下一步

把產生的 brief 貼回 [[CreateWithLevi]] 或對應 project，並決定它是 L1 Public Draft、L2 Distributed，還是 L3 Packaged。
