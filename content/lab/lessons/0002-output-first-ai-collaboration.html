Lesson 0002

先定義輸出，再和 AI 協作

這堂課只練一個動作：不要從「我有好多東西」開始，而是從「我想產出哪一種具體成果」開始。

今天的勝利條件：把一個 input 轉成一句可以直接丟給 AI 的 output-first prompt。

核心觀念

AI 很適合幫你展開、整理、比較、產生初稿。但如果你只丟一堆 input，它很容易把事情整理得很完整，卻不一定變成你真正需要的成果。

所以先問：

這次我想得到的具體成果是什麼？
是一篇文章？一個決策？一份 checklist？一段回覆？一個產品規格？還是一個下一步行動？

三句 Prompt 模板

1. Input：我剛看到 / 經歷的是……

2. Question：我現在真正需要學會或判斷的是……

3. Output：請先幫我做出一個……，我會再用自己的判斷修正。

練習 1：選 output

情境 A：客戶提出一個新需求，但你不確定該不該做，也不確定成本。你最需要的輸出是？

情境 B：你剛完成一個很有感的學習，想讓它變成公開思考。你最需要的輸出是？

情境 C：你整理了很多想法，但發現現有行動沒有改變。你最需要的輸出是？

練習 2：產生你的 output-first prompt

下一次怎麼用

當你準備丟 input 給 AI 前，先停 10 秒，選一個 output 類型。這會讓 AI 從「整理者」變成「成果協作者」。

如果你不確定 output 是什麼，可以先問 agent：「這份 input 最值得變成哪三種具體成果？請按對我目前 Goal 的價值排序。」

推薦讀物

回看 具體成果迴圈 reference。這次重點只看第 2 步 Question 與第 4 步 Concrete Output。

這堂課接續 Lesson 0001。完成後，請把最有價值的 output 寫回 Obsidian 的 Project / Area / Goal 或 Current Action。
