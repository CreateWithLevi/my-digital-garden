Interactive practice

練習：把 input 壓成具體成果

這個區塊只保留互動練習。完整概念、延伸閱讀與課堂連結請看外層 Markdown lesson。

勝利條件：把一個輸入轉成「下一個最小具體成果」。

練習 1：判斷具體成果類型

選出最適合的具體成果。重點不是答對題目，而是練習判斷「哪種 output 最能推進下一步」。

情境 A：你讀到一篇個人品牌文章，覺得它和自己的定位有關，但還沒有完整論點。

情境 B：你在 Zouluh 發現「銀行連結」可能太早要求，想釐清產品入口策略。

情境 C：你發現自己對 GIL / thread 不熟，但短期不是為了面試刷題，而是要能講清楚。

練習 2：把你現在的題目壓成一個具體成果

用 3 句話填。不要查資料，先 retrieval。
