具體成果影響力地圖

把具體成果從「我做出一個東西」推進到「它能被使用、收到回饋，必要時再形成產品或服務」。

核心路徑

1. Output
文章、lesson、template、demo、case study。
2. Destination
目前的專案、Digital Garden、repo、作品集或一場對話。
3. Use
讓一個真實的人或情境理解、測試或回應。
4. Feedback
實際使用結果、問題、反例、留言、DM 或新的需求。
5. Offer
template、workshop、service、consulting、product。
6. Business
接案、工作機會、付費內容、數位產品、SaaS。

目的地速查

目的地 最適合 主要問題
目前的專案或工作 決策、規格、流程、prototype 它是否直接改善下一步？
Digital Garden 長文、公開筆記、lesson、case study 另一個人是否能理解並帶回自己的情境？
GitHub repo、skill、prompt、HTML lab、demo 成果是否能被檢查、使用或 fork？
Portfolio / Service page case study、服務流程、精選成果 它是否能證明能力與判斷？
社群或對話 獨立觀點、問題、短案例 這裡是否有真正相關的人？

最小實驗

先做：選一個已完成具體成果 → 找到一個真正需要它的人或情境 → 讓對方使用或回應 → 根據一個具體反饋更新原成果。
